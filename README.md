# E-Commerce Data Analysis using REST API

## Project Overview
This project analyzes e-commerce product data fetched from the Fake Store REST API using Python.

## Tools Used
- Python
- Requests
- Pandas
- Matplotlib
- Jupyter Notebook

## Features
- Fetch data from REST API
- Convert JSON to DataFrame
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights

## Key Analysis
- Product Categories
- Average Price
- Highest & Lowest Priced Products
- Highest Rated Products
- Most Reviewed Products

## Project Outcome
This project demonstrates API integration, data analysis, and visualization techniques used in real-world data analytics.
